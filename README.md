# Bodega La Sacristía · Página Web

🌿 Sitio web oficial para **Bodega La Sacristía**, un bar con encanto andaluz ubicado en Almensilla (Sevilla), donde tradición y buen ambiente se encuentran para ofrecer una experiencia única.

## 🌐 Enlace al sitio

👉 [https://tuusuario.github.io/la-sacristia](https://tuusuario.github.io/la-sacristia)

---

## 📂 Estructura del proyecto

- `index.html` — Página de inicio
- `sobre-nosotros.html` — Sobre el bar
- `eventos.html` — Información sobre eventos culturales, privados y empresariales
- `menu.html` — Carta de comidas y bebidas
- `contacto.html` — Información de contacto y motor de reservas
- `/images/` — Imágenes utilizadas en la web
- `/styles/` — Hojas de estilos (SASS/CSS)
- `/scripts/` — Scripts JS para animaciones y funcionalidad

---

## ✨ Funcionalidades

- Animaciones de entrada con [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
- Diseño responsive adaptado a móviles, tablets y pantallas grandes
- Motor de reservas integrado vía widget externo (Dish.co)
- Estética cuidada con fondo de madera y paleta cálida
- Accesible y fácilmente navegable

---

## 🛠️ Tecnologías utilizadas

- HTML5
- SASS (CSS preprocesado)
- JavaScript (vanilla)
- AOS Library para animaciones (`fade-left`, `fade-right`, etc.)
- Git + GitHub Pages para despliegue
